# Asylum Base v0.4.4 — Community Content Platform

Одна сборка объединяет четыре ранее запланированных этапа:

- составы и связки;
- события и календарь;
- реакции и аналитику;
- предложения контента от участников.

## Новые публичные команды

- `/heroes [имя]`
- `/squads`
- `/events`
- `/suggest TYPE | Заголовок | Текст`

## Новые административные команды

- `/hero_add`
- `/squad_add`
- `/event_add`
- `/content_add`
- `/content_queue`
- `/content_pause ID`
- `/content_resume ID`
- `/suggestions`
- `/analytics`

## Маршрутизация

- `hero` и `squad` → тема героев;
- `event` → тема новостей;
- `guide` → тема новичков/гайдов;
- `alliance` → тема альянсов.

## Безопасность

- автопостинг контента выключен по умолчанию;
- дневной лимит по умолчанию — один пост;
- события получают приоритет в очереди;
- предложения игроков не публикуются напрямую;
- новые таблицы создаются через `CREATE TABLE IF NOT EXISTS`;
- изображения хранятся как Telegram `file_id`, а не как файлы на VPS.
