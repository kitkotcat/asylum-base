# Приёмочный чек-лист v0.3.0

## Smoke

- [ ] сервис `active`;
- [ ] запущен один процесс `bot.app.main`;
- [ ] в логах нет `Traceback`, `database is locked`, `no such table`;
- [ ] `/start` показывает четыре пользовательских раздела;
- [ ] технических команд нет в публичном меню;
- [ ] `/admin` доступна только администратору.

## Deals

- [ ] `/deals` показывает страницу предложений;
- [ ] работают `◀️` и `▶️`;
- [ ] процент купона не дублируется;
- [ ] кнопка ведёт на `LOOTBAR_AFFILIATE_URL`;
- [ ] baseline не создаёт публикации;
- [ ] незначительное изменение цены не создаёт автопост;
- [ ] значимое снижение создаёт отдельный черновик;
- [ ] карточка содержит изображение, три цены, экономию и условие;
- [ ] повторный запуск не создаёт дубль;
- [ ] cooldown не публикует один пакет повторно;
- [ ] лимит постов за 6 часов соблюдается.

## News and Google Play

- [ ] RSS baseline не создаёт старые новости;
- [ ] новая RSS-запись создаёт красивый черновик;
- [ ] Google Play update публикуется в тему новостей;
- [ ] кнопка ведёт на исходный материал.

## Promo

- [ ] `/promo_add` принимает дату и регион;
- [ ] `/promocodes` показывает срок и статус;
- [ ] голосование работает;
- [ ] истёкший код автоматически отключается;
- [ ] `/promo_expire` отключает код вручную.

## Daily jobs

- [ ] Top-3 создаётся не чаще одного раза в день;
- [ ] отчёт администратору создаётся не чаще одного раза в день;
- [ ] отчёт показывает пользователей, публикации, ошибки и черновики.
