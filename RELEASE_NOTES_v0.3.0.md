# Asylum Base v0.3.0 — Content Platform

Одна сборка объединяет Auto Publishing MVP, UX Cleanup и Content Engine.

## Главное

- красивые отдельные карточки значимых LootBar-скидок;
- изображение пакета и партнёрская inline-кнопка;
- очередь, журнал, cooldown, rate limit и защита от дублей;
- ежедневный Top-3 дайджест;
- новый `/start` и чистое публичное меню;
- `/deals` с пагинацией;
- RSS и Google Play публикации;
- промокоды с регионом и сроком действия;
- ежедневная статистика администраторам;
- безопасное поэтапное включение через feature flags.

## Важное изменение

Автопубликация выключена по умолчанию. После деплоя сначала выполняется ручная приёмка, затем источники включаются по одному.
