# Asylum Base

Telegram-платформа для русскоязычного сообщества игроков Last Asylum: Plague.

## Компоненты

- Telegram-группа с тематическими разделами
- Telegram-бот
- FastAPI backend
- PostgreSQL
- Telegram Mini App
- Партнёрская аналитика

## Статус

Проект находится на этапе разработки MVP.

## Структура

- `bot/` — Telegram-бот
- `backend/` — API и бизнес-логика
- `frontend/` — Telegram Mini App
- `docs/` — документация проекта
